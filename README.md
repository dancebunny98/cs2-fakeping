
## Команды

Все команды доступны только администраторам с правом `@css/root`.

- **`!fakeping <игрок> <пинг>`**  
Устанавливает фейковый пинг.  
Примеры:
- `!fakeping #123 200` — игроку с userid 123 установить 200 мс.
- `!fakeping @all 999` — всем игрокам установить 999 мс (поддерживается `@all`, `@ct`, `@t`).
- `!fakeping "NickName" 150` — игроку с именем NickName установить 150 мс (регистр не важен).

- **`!fakeping_remove <игрок>`**  
Убирает фейковый пинг.  
Пример: `!fakeping_remove #123` или `!fakeping_remove NickName`.

## Права доступа

По умолчанию используется флаг `@css/root`. Чтобы изменить его, отредактируйте атрибут `[RequiresPermissions("@css/root")]` в коде на нужный вам флаг, например `@css/slay`.
